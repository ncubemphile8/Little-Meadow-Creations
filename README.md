# Little Meadow Creations

A boutique storefront starter for Little Meadow Creations.

## Run locally

```bash
npm install
npm run dev
```

## Notes
- Separate routes: Home, Shop, Gift Boxes, Our Story and Contact.
- Page transitions and a lightweight hopping-bunny motif are included.
- Product prices are seeded from the owner's supplied price list.
- Product image slots are intentionally placeholders until the supplied original assets are uploaded and matched to products.
- Checkout/payment processing, stock management and delivery rules are not yet connected. WhatsApp contact is available as an initial enquiry channel.

Deploy on Vercel with the default Vite settings (build: `npm run build`, output: `dist`).
