# Little Meadow Creations

A responsive handmade-gifts storefront for Little Meadow Creations.

## Run locally
```bash
npm install
npm run dev
```

## Included
- Home, Shop, Gift Boxes, Our Story and Contact pages with real route navigation.
- Product detail pages for the supplied price-list catalogue.
- Search and category filters.
- Shopping bag with quantity controls and browser-local persistence.
- WhatsApp order-enquiry checkout with order lines and customer details.
- Hopping bunny page-transition motif and responsive mobile navigation.
- Vercel SPA rewrite so nested routes load directly.

## Before accepting live paid orders
- Replace the catalogue art placeholders with the owner's original product photographs.
- Confirm the WhatsApp number, Instagram profile URL, stock and made-to-order lead times.
- Add delivery fees, returns/privacy terms and a payment provider if card or instant online payment is required.

## Deploy
Vercel build command: `npm run build`; output directory: `dist`.
